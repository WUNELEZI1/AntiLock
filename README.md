# 星特反锁机 (AntiLock)
通过 Shizuku / Root 与无障碍服务实现的被动反制锁机工具

## 功能
- 无障碍取消：通过Shizuku执行命令停用对应应用无障碍权限
- 卸载列表：一键强制卸载恶意应用
- 强制置顶：防止无障碍服务被恶意关闭和悬浮窗被覆盖
- 物理触发：快速按 10 下音量- 打开卸载列表
- 应急键盘：切换键盘显示卸载入口，部分系统不生效
- 深浅色适配 + 动态取色(仅支持Android12+)
- Root 模式：Root 环境下可直接执行卸载等命令

## 构建
使用 Android Studio 或 AIDE 打开项目直接构建。
依赖：app/libs/ 下的 Shizuku 库。

## 声明
1.反锁机仅支持无障碍、强制置顶等锁机，不支持通过管理员权限，修改设备密码的
2.为了防止误杀，反锁机需要手动操作，无法做到自动执行卸载
3.禁止用于盈利性项目上
4.为了方便，源码请下载AntiLock-src.zip
